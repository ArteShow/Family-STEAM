# User Manual

This guide explains the main tasks in plain language.

## 1. Register an Account

1. Open the site in your browser.
2. Go to the login or registration page.
3. Enter your username and password.
4. Confirm the password if the form asks for it.
5. Select the registration button.
6. Wait for the success message.
7. Sign in with the new account.

## 2. Log In

1. Open the login page.
2. Enter your username.
3. Enter your password.
4. Select the login button.
5. If the details are correct, you will be taken to your dashboard or settings page.

## 3. Use the Dashboard

1. Open the dashboard after logging in.
2. Use the navigation menu to switch between admin tools and user tools.
3. Read any messages or alerts shown on screen.
4. Log out when you are done.

## 4. Users

1. Open the users area from the dashboard.
2. Review the user list if you have access.
3. Open a user record to view details.
4. Save changes if you are editing a record.

## 5. Clients

1. Open the clients area.
2. Add a new client using the form.
3. Edit client information when needed.
4. Delete the client only if you are sure it is no longer needed.

## 6. Calendar

1. Open the calendar or events page.
2. View upcoming events.
3. Add or edit an event if your role allows it.
4. Save your changes.

## 7. Files

1. Open the files section.
2. Select a file to upload.
3. Wait for the upload confirmation.
4. Download or delete files only if you have permission.

## 8. Messages

1. Open the messages page.
2. Read new messages in your inbox.
3. Reply from the message thread if needed.
4. Keep the conversation organized by closing finished threads.

## 9. Reviews

1. Open the reviews section.
2. Read the reviews list.
3. Add a review if the page allows it.
4. Remove a review only if you have the right permission.

## 10. Newsletters

1. Open the newsletter page.
2. Subscribe with your email address.
3. Unsubscribe if you no longer want updates.
4. Admin users can send newsletter campaigns.

## 11. Tickets

1. Open the tickets section.
2. Create a new ticket when you need help.
3. Check your ticket status later.
4. Reply to the ticket thread if support asks for more information.

## Common Problems

- If a page does not load, refresh the browser.
- If login fails, check your username and password.
- If a form does not submit, make sure all required fields are filled in.
- If you still have trouble, contact the site administrator.
